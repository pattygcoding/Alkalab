How it works

  • One flat buffer. The grid is a single Vec<Cell>; (x, y) maps to y * width + x and a one cell inert border removes every bounds check.
  • Bottom-up ticks. Rows are scanned bottom to top so falling material cannot be updated twice, and the column direction flips every frame so water has no favourite side. Anything that moves sideways or up is stamped with the frame number and skipped.
  • Density, not special cases. Sand sinks in water, oil floats on it, mercury sinks through both - one rule, no per-element code.
  • Zero-copy pixels. Rust renders straight into a Uint8ClampedArray view of wasm memory; JavaScript hands that buffer to putImageData. No data crosses the boundary per frame.
  • Chemistry table. 2 Na + 2 H2O -> 2 NaOH + H2, CaC2 + 2 H2O -> Ca(OH)2 + C2H2, sand + lava -> glass: reactions are declarative rows with a probability, an outcome per side and an equation for this log.
Built with Rust + wasm-bindgen. The simulation core is plain std Rust and is unit tested natively with cargo test.
